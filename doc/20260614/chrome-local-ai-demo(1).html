用不了？开启方法

1. 使用 Chrome 138+（建议最新稳定版 / Canary）。
2. 地址栏打开 chrome://flags/#prompt-api-for-gemini-nano → 设为 Enabled。
3. 打开 chrome://flags/#optimization-guide-on-device-model → 设为 Enabled BypassPerfRequirement。
4. 重启浏览器后，在 chrome://on-device-internals 确认模型下载完成（约 2~4 GB，需较新 GPU 和足够磁盘空间）。
5. 本页面需通过 http(s):// 或 localhost 打开（如 npx serve），部分版本不支持 file://。
